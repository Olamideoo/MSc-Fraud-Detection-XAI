# An Explainable AI Framework for Fraud Detection and Transaction Risk Scoring in Digital Banking Platforms

## Project Overview

This project investigates the application of Explainable Artificial Intelligence (XAI) techniques to fraud detection and transaction risk scoring in digital banking environments.

The study evaluates the balance between predictive performance and model interpretability by comparing Logistic Regression, XGBoost, and LightGBM classifiers. The project further integrates SHAP and LIME to provide global and local explanations of model predictions.

The overall aim is to demonstrate how machine learning models can support fraud detection while providing transparent and interpretable outputs that can assist financial institutions with model understanding, auditing, and fraud investigation.

---

## Research Aim

To design, develop, and evaluate an explainable machine learning framework for fraud detection and transaction risk scoring in digital banking environments.

---

## Research Objectives

1. **Data Understanding and Preprocessing:** Explore and preprocess the banking transaction dataset to prepare it for machine learning analysis.

2. **Feature Engineering:** Develop domain-informed behavioural risk indicators to improve the identification of potentially fraudulent transactions.

3. **Model Development:** Develop and evaluate Logistic Regression, XGBoost, and LightGBM classification models for fraud detection.

4. **Performance Evaluation:** Compare model performance using appropriate classification metrics, including accuracy, precision, recall, F1-score, and ROC-AUC.

5. **Explainable AI Integration:** Apply SHAP and LIME to provide global and local explanations of model predictions.

6. **Interpretability Analysis:** Examine whether the explanations generated by SHAP and LIME provide consistent insights into the factors contributing to fraud predictions.

---

## Dataset

The project uses a synthetic banking transaction dataset containing **10,000 transactions** with a natural fraud distribution of approximately **12.51%**.

The dataset contains transaction, behavioural, account, authentication, and risk-related variables used to investigate patterns associated with fraudulent activity.

### Target Variable

`fraud_flag`

- `0` = Legitimate transaction
- `1` = Fraudulent transaction

---

## Machine Learning Models

Three classification algorithms were evaluated:

1. **Logistic Regression**  
   Used as a transparent linear baseline for comparison.

2. **XGBoost**  
   A gradient boosting model capable of capturing non-linear relationships between transaction characteristics.

3. **LightGBM**  
   A gradient boosting framework evaluated for its predictive performance and suitability for fraud classification.

---

## Explainable AI Methods

### SHAP

SHAP (SHapley Additive exPlanations) was used to examine both global and local model behaviour. It provides insight into the contribution of individual features to model predictions and helps identify the factors that most strongly influence fraud classifications.

### LIME

LIME (Local Interpretable Model-agnostic Explanations) was used to generate local explanations for individual transactions by approximating the behaviour of the underlying machine learning model around specific predictions.

The study compares SHAP and LIME explanations to assess the consistency of their interpretations.

---

## Model Evaluation

The models were evaluated using classification metrics appropriate for fraud detection, including:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion matrix

Particular attention was given to fraud-class performance because fraudulent transactions represent the minority class within the dataset.

---

## Key Findings

The experimental results showed that gradient-boosted tree models were able to capture non-linear relationships within the transaction data more effectively than the Logistic Regression baseline.

The optimised LightGBM model achieved:

- **Accuracy:** 95.30%
- **Precision:** 82.77%
- **ROC-AUC:** 97.79%

Optimised XGBoost achieved the highest fraud recall of:

- **Recall:** 79.60%

The XAI analysis further identified `anomaly_score` as the most influential feature in the model explanations. SHAP and LIME provided complementary local and global perspectives on the factors contributing to fraud predictions.
